Şifrelerimi nereden dışa aktarırım?
  • iPhone (Safari / Şifreler): Ayarlar → Uygulamalar → Safari → Geçmiş ve Web Sitesi Verileri bölümünde Dışa Aktar → sadece Parolalar. İnen ZIP dosyasını açmadan doğrudan burada seç.
  • Mac: Şifreler uygulaması → Dosya → Tüm Şifreleri Dosyaya Aktar.
  • Chrome: Ayarlar → Google Şifre Yöneticisi → Ayarlar → Dosyayı indir (dışa aktar).
  • Google hesabı: passwords.google.com → Ayarlar → Şifreleri dışa aktar.
  • Edge: Ayarlar → Profiller → Şifreler → ⋯ → Şifreleri dışa aktar.
  • Firefox: about:logins → ⋯ → Girişleri dışa aktar.

Menü adları sürüme göre biraz farklı olabilir.

Aktarma bitince dışa aktardığın CSV/ZIP dosyasını sil. O dosyada şifreler açık yazılıdır.
